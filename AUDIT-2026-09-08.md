# Focused security and workflow audit — 2026-09-08

## Decision

Keep ChatGPT as the reasoning layer and MacBridge as the deterministic executor.
Add only MB Operator guidance, an optional small checkpoint, and structured
evidence. Do not add a model, agent runtime, workflow database, parallel scheduler,
privileged helper, new dependency, or new network route.

## Baseline and scope

- Source baseline: commit `46a00f1ec8c90752937213304d6e8ff9bd604003`.
- Audited paths: direct reads, special files and path replacement; credential
  exclusions; command sandbox; control-plane reach; loopback-only networking;
  developer gateway, task state, checkpoint and evidence behavior.
- External acquisition: none. The Swift package still has no third-party package
  dependencies. Tests use only synthetic, non-secret fixtures.
- Installed runtime: unchanged during this audit. Source and serving artifacts
  remain separate until exact-artifact review and normal-Chat acceptance.

## Confirmed findings and minimal fixes

1. **FIFO request stall — fixed.** A direct `file_read` opened a pathname in
   blocking mode before confirming it was a regular file. A synthetic FIFO call
   remained unanswered after 750 ms. The read now uses non-blocking,
   no-ancestor-symlink flags and validates the opened descriptor as a single-link
   regular file. Regression: special file rejected in milliseconds; regular reads
   remain unchanged.
2. **Environment template over-blocking — fixed without opening secrets.** Exact
   final names `.env.example`, `.env.sample`, `.env.template`, and `.env.dist` are
   readable. `.env`, other `.env.*` variants, and content below a template-named
   directory remain denied in direct tools and the command sandbox.
3. **Workflow completion ambiguity — reduced in guidance.** Every initialized MCP
   session receives a compact outcome → inspect → act → verify → repair/finish
   loop. The reusable skill defines a small checkpoint and truthful evidence
   report. Neither is an authority or completion oracle.

## Residuals kept explicit

- Hashing and atomic replacement still include pathname-based operations. No
  reliable in-scope exploit was demonstrated in this pass; a robust directory-fd
  redesign is deferred rather than shipped without evidence.
- Loopback access can reach services owned by the same account. Non-loopback
  networking remains denied; no general internet capability was added.
- Broad mode intentionally permits current-user work under an explicit non-root
  command directory. Accident guards are not malware containment, and MacBridge's
  own credential/config paths remain blocked.
- The host decides tool discovery, normal-Chat callability, approvals and embedded
  card rendering. Local tests cannot certify those surfaces.

- The final full Swift suite passed 279 tests with zero failures.
- The exact Release core SHA-256 is
  `92d183067b5d91ca9999bf50f8411eef9d9caeb3d607c714627c6309c0a219e6`.
  Its catalog has 55 tools with SHA-256

- Desktop-local and web-tunnel each passed 181 finite E2E checks against that
  same core. The operator fixture performed inspect, edit, test, diff review,
  independent hash readback and rollback, then left no retained process handle.
- Packaging passed 19 cases and three manifest self-checks without changing its

  verification and contains only Apple system libraries plus Swift runtime
  libraries. It is ad-hoc signed, has no Developer ID/notarization, and Gatekeeper
  assessment rejects it; this limitation is not reported as a PASS.

## Live cutover still required

The serving runtime remains unchanged. Before live use: perform the idle/undo
preflight, obtain explicit approval for the exact Trust-B artifact, install and
restart it, then run normal-Chat read, mutation/restore, process and operator
workflow acceptance against the installed owner. Host discovery and rendering
cannot be certified by local tests.
